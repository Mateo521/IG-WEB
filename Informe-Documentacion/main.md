# Descripción del Proyecto

El proyecto consiste en el desarrollo de un sistema web para la gestión
de un PoliRubro, permitiendo visualizar productos organizados por
rubros, subrubros y categorías.

El sistema contará con:

## Módulo Cliente

- Visualización de productos

- Filtros por categorías

- Búsqueda de productos

- Consulta de productos

## Módulo Administrador

Gestión completa (CRUD) de:

- Productos

- Rubros

- Subrubros

- Categorías

- Consultas realizadas

# Objetivo General

Desarrollar una aplicación web moderna, escalable y organizada mediante
la metodología SCRUM, aplicando buenas prácticas de desarrollo frontend,
backend y bases de datos.

- El código esté integrado
